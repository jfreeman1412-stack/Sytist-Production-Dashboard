Phase 10a — line-items picker for live preview

═══════════════════════════════════════════════════════
THE PROBLEM
═══════════════════════════════════════════════════════

To preview a layout against a real order, the previous workflow
required you to type both an Order ID AND a Cart ID. The cart
ID is an internal database PK with no operator-facing UI to
look it up — you'd have to query MySQL directly. Practically
unusable.

═══════════════════════════════════════════════════════
THE FIX
═══════════════════════════════════════════════════════

Replaced the Cart ID text input with a clickable line-items
picker:

1. Type an Order ID
2. Click "Load"
3. The order's photo line items appear as a scrollable list
   with thumbnails, product names, SKUs, photo filenames,
   and (subtly) cart IDs for reference
4. Click a row → that line item is selected
5. Preview renders against that selection

If an order has only one photo line item, it's auto-selected.
Saves one click on simple orders.

If an order has no photo line items (e.g., gift cert only,
download only), the picker shows an error.

If an order doesn't exist at all, the Load button reports
"Order not found."

═══════════════════════════════════════════════════════
WHAT THE LIST SHOWS
═══════════════════════════════════════════════════════

Each row:
  [thumb 48×48]  Memory Mate 8x10

Plus a subtle 🖼️ indicator on rows that have a green-screen
background photo, so you can quickly find a green-screen line

Selected row gets a blue-tinted background and left border.

═══════════════════════════════════════════════════════
HOW IT FEELS NOW
═══════════════════════════════════════════════════════

Open the layout designer. Click "Use real order data."

Type an order ID (the same ones you'd see in the Orders page).
Click Load. A list of that order's photo line items appears
below the input. Click whichever line item you want to preview
against. The preview canvas renders.

If the order has just one photo line item, you don't even
need to click — it auto-selects.

To preview against a different order: type a new order ID.
The list of line items disappears (since they were for the
old order). Click Load again.

═══════════════════════════════════════════════════════
KNOWN GAPS
═══════════════════════════════════════════════════════

- THUMBNAILS ARE FETCHED FROM S3 SAME WAY AS THE EXISTING
  LOGO/PHOTO SYSTEM: thumb URLs come from buildPhotoUrls().
  If S3 is slow or thumbnails are missing, the picker shows
  empty placeholders. The list itself still works.

- NO ORDER SEARCH/AUTOCOMPLETE: you still need to know an
  order ID to load. Future: type-ahead from recent orders or
  a "find order" lookup. For now, operators copy IDs from the
  Orders list page.

- LINE ITEMS LIST DOESN'T REFRESH AUTOMATICALLY: if you load
  order X, then someone else modifies order X's cart in the
  background, you'd need to re-click Load to see the change.
  Acceptable for a single-operator preview tool.
