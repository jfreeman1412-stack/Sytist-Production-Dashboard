Phase 13a hotfix #5 — fs-extra dependency removed

═══════════════════════════════════════════════════════
WHAT THIS REPLACES
═══════════════════════════════════════════════════════

Supersedes hotfix-4. Carries everything (server/index.js
wiring, requireAuth inside route file, error UI states) and
fixes a missing-dependency crash.

═══════════════════════════════════════════════════════
WHAT WAS CRASHING
═══════════════════════════════════════════════════════

Server log showed:

  MODULE_NOT_FOUND
  requireStack:
    C:\...\server\config\appSettings.js
    C:\...\server\services\shipstationService.js
    C:\...\server\routes\shipstation.js
    C:\...\server\index.js

appSettings.js was using `fs-extra`, which the PhotoDay project
had as a dependency but Sytist doesn't. The crash happened on the
require chain triggered by my new index.js edits.

═══════════════════════════════════════════════════════
THE FIX
═══════════════════════════════════════════════════════

Rewrote appSettings.js to use Node's built-in `fs` module
(already used by orderOverrideService and databaseService in
your project). Same JSON file format on disk, same public API,
zero new dependencies.

Specifically:
  - Replaced `require('fs-extra')` with `require('fs')` +
    `fs.promises`
  - Added four small local helpers (readJsonAsync,
    writeJsonAsync, readJsonSync, writeJsonSync) that do what
    fs-extra's helpers did, two lines each
  - Updated the six call sites in _ensureConfig, _read,
    _write, getRawValueSync

═══════════════════════════════════════════════════════
WHY THE LIBRARIES ARE INCONSISTENT
═══════════════════════════════════════════════════════

Honest answer: I ported PhotoDay's appSettings.js as-is in 13a
without auditing dependencies. PhotoDay used fs-extra throughout
its codebase; Sytist uses built-in fs. The right move was to
adapt to Sytist's conventions at port time. I'll be more careful
about this on the remaining 13b/13c/13d/13e/13f ports — every
service from PhotoDay needs a quick scan for project-specific
deps before bundling.
