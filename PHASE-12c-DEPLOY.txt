Phase 12c — aspect-correct 150px thumbnails

═══════════════════════════════════════════════════════
WHAT CHANGED
═══════════════════════════════════════════════════════

Line item thumbnails on the order detail page were locked
to 80×80, cropping via objectFit:cover. Now they scale to
150px on the long edge with the short edge respecting the
photo's native aspect ratio.

  Vertical photo (e.g. 1920×2400): 120×150 tile
  Horizontal photo (e.g. 4124×3299): 150×120 tile
  Square photo: 150×150 tile
  Photo with no width/height in API: fall back to 150×150

Dimensions are computed from photo.width/photo.height in the
API response BEFORE the image loads, so the page layout
doesn't shift when the image finishes downloading.

For green-screen items, the background and player still
stack at the same tile dimensions — the player photo's
aspect ratio drives the tile, and the background fills it
behind. Final layout still arranges them per the layout
slot specs at render time; this is just a thumbnail preview
of which inputs go together.
