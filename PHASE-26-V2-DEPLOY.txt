Phase 26-v2 — Hotfix: hooks rules violation

V1 BUG: the new useRef + useState + useEffect for the responsive
canvas sizing were placed AFTER `if (loading) return` and
`if (!layout) return null` early returns. On first render (when
loading=true) the early return ran before reaching the hooks; on
later renders (loading=false) all hooks ran. React saw a different
hook count and threw:

  Rendered more hooks than during the previous render.

V2 FIX: moved the 3 new hooks to BEFORE the early returns. Math
that depends on `layout` (aspect, canvasWidth/canvasHeight) stays
after the early returns where layout is guaranteed non-null.
